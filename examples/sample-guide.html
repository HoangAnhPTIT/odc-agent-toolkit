Acme Orders: order notes (ORD-42)

Spec ORD-42 v1.0, Order notes (1 Jan 2030). Read top to bottom: every section is one piece of work in ODC Studio, in build order. Structures come with JSON samples; click any value to copy it (copied values stay green, the bar at the bottom right jumps back to the last one).

The flow in one paragraph. On the order card the user taps Add note, types up to 200 characters and taps Save. The note is saved on the server and shown under the order total. An empty note removes it.
